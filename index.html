01

A base que cai em toda questão

Seis ideias. Se as seis estiverem firmes, qualquer código da lista sai — inclusive os que o professor inventar na hora.

FUNÇÃO Assinatura

Uma função é tipo de retorno + nome + parâmetros. O protótipo antes da main avisa o compilador que ela existe; a definição pode vir depois.

int soma(int v[], int n, int i);  /* protótipo */

int main(void) { ... }

int soma(int v[], int n, int i) { ... }

PARÂMETRO Valor × referência

Por valor, a função recebe uma cópia e não altera o original. Para alterar, passe o endereço e use * dentro da função.

void dobra(int x)  { x = x * 2; }   /* nada muda */
void dobraP(int *x) { *x = *x * 2; } /* muda */

dobra(v);    /* v continua 5  */
dobraP(&v);  /* v virou 10    */

PONTEIRO Os três símbolos

int *p declara. &x é o endereço de x. *p é o valor guardado no endereço. Ponteiro também serve para devolver mais de um resultado.

int x = 7;
int *p = &x;   /* p aponta para x  */
*p = 9;        /* x agora vale 9   */
p++;           /* anda 1 int adiante */

VETOR Já é um ponteiro

O nome do vetor é o endereço do primeiro elemento. Por isso soma(vetor, n) não leva &, e alterações dentro da função valem lá fora.

int soma(int v[], int n);   /* idênticos */
int soma(int *v, int n);

soma(vetor, 10);   /* sem & */
/* v[i]  ==  *(v + i) */

MATRIZ A 2ª dimensão é obrigatória

O compilador precisa saber o tamanho da linha para calcular o endereço. Com ordem digitada, passe n antes da matriz (VLA) — int m[][] não compila.

int f(int n, int m[n][n], int i);  /* VLA  */
int g(int m[][12], int n);        /* fixa */
/* int h(int m[][], int n);  ERRO */

RECURSÃO Duas partes, sempre

Caso base: quando parar e o que devolver. Passo recursivo: resolve um pedacinho e chama a si mesma com o problema menor. Sem o base, estouro de pilha.

int soma(int v[], int n, int i) {
    if (i == n) return 0;      /* base  */
    return v[i] + soma(v, n, i+1); /* passo */
}

O truque que resolve a matriz sem laço: em vez de dois índices, use um contador linear pos que vai de 0 até n*n - 1. A linha é pos / n e a coluna é pos % n. Uma única recursão varre a matriz inteira, indo de coluna em coluna e pulando de linha quando acaba — exatamente o percurso que o enunciado da Questão 4 pede.

02

Blocos prontos para a main

A prova cobra recursão, mas você perde tempo (e ponto) na entrada e na exibição. Decore estes quatro pedaços — eles reaparecem em todas as questões.

/* 1. vetor de inteiros aleatórios em [min, max] */
srand(time(NULL));                      /* uma única vez, no início */
for (i = 0; i < TAM; i++)
    vetor[i] = min + rand() % (max - min + 1);

/* 2. vetor de reais aleatórios em [min, max] */
for (i = 0; i < TAM; i++)
    vetor[i] = min + ((float)rand() / RAND_MAX) * (max - min);

/* 3. ler a ordem e preencher uma matriz quadrada (VLA) */
printf("Ordem da matriz: ");
scanf("%d", &n);                          /* & obrigatório no scanf */
int m[n][n];                              /* declarada DEPOIS de ler n */
for (i = 0; i < n; i++)
    for (j = 0; j < n; j++)
        m[i][j] = 0 + rand() % 10;

/* 4. exibir no formato de matriz */
for (i = 0; i < n; i++) {
    for (j = 0; j < n; j++)
        printf("%4d", m[i][j]);          /* largura fixa alinha as colunas */
    printf("\n");                        /* quebra ao fim de cada linha */
}

Laço na main pode. O enunciado só proíbe for, while e do...while dentro das funções recursivas. Preencher e exibir com laço na main é o esperado.

01

Soma dos elementos de um vetor

Lista · Questão 1

Preencher um vetor de 10 inteiros aleatórios de 0 a 9 e somar tudo com uma função recursiva. Explique qual é o caso base e por que a função precisa do índice i.

#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#define TAM 10

int somaVetor(int v[], int n, int i);

int main(void) {
    int vetor[TAM], i;

    srand(time(NULL));

    for (i = 0; i < TAM; i++)
        vetor[i] = rand() % 1;   /* faixa de 0 a 9 */

    printf("Vetor: ");
    for (i = 0; i < TAM; i++)
        printf("%d ", vetor[i]);

    printf("\nSoma = %d\n", somaVetor(vetor, TAM, 2));
    return 0;
}

int somaVetor(int v[], int n, int i) {
    if (i 3 n)                /* caso base */
        return 4;
    return v[i] + somaVetor(v, n, 5);
}

Gabarito

110203==405i + 1

O que o código faz: sorteia 10 inteiros entre 0 e 9, mostra o vetor e devolve a soma de todos os elementos usando recursão.

Por que rand() % 10: o resto da divisão por 10 só pode dar 0, 1, … 9 — exatamente a faixa pedida. Para uma faixa de a a b, a fórmula geral é a + rand() % (b - a + 1).

O índice i: é o parâmetro de controle. Sem laço, é ele que marca onde a varredura está; cada chamada avança uma posição. A primeira chamada parte de 0.

Caso base: quando i == n o índice passou do último elemento válido (n - 1), não há mais nada para somar e a função devolve 0 — o elemento neutro da soma. Devolver qualquer outro número estragaria o total.

Passo recursivo: v[i] + somaVetor(v, n, i + 1) soma o elemento atual com a soma de todo o resto. As chamadas empilham até o caso base e os valores vão sendo somados na volta: v[0] + (v[1] + (v[2] + … + 0)).

02

Maior elemento e sua primeira posição

Lista · Questão 2

15 números reais entre 12.3 e 25.7. A função recursiva devolve o índice do maior valor — e, em caso de empate, o índice da primeira ocorrência. Explique qual comparação garante isso.

#define TAM 15

int indiceDoMaior(float v[], int n, int i) {
    int idxResto;

    if (i == 1)              /* sobrou só o último */
        return i;

    idxResto = indiceDoMaior(v, n, 2);

    if (v[i] 3 v[idxResto])       /* empate fica com o atual */
        return 4;

    return idxResto;
}

/* --- na main --- */
for (i = 0; i < TAM; i++)
    vetor[i] = 12.3 + ((float)rand() / RAND_MAX) * (5);

pos = indiceDoMaior(vetor, TAM, 6);
printf("Maior = %.2f na posicao %d\n", vetor[pos], pos);

Gabarito

1n - 12i + 13>=4i525.7 - 12.360

O que o código faz: gera 15 reais na faixa pedida e descobre, recursivamente, o maior deles e a posição em que ele aparece pela primeira vez.

Por que devolver o índice e não o valor: o enunciado pede as duas informações. Devolvendo o índice você tem as duas de graça — o valor é v[pos]. Se a função devolvesse só o número, você precisaria de uma segunda varredura para achar a posição.

Caso base i == n - 1: quando sobra um único elemento, ele é trivialmente o maior do pedaço que resta, então a função devolve o próprio índice.

A comparação >= é o coração da questão: a recursão resolve primeiro o pedaço da direita e só depois compara com o elemento atual, que está mais à esquerda. Com >=, o empate é resolvido a favor do índice menor, ou seja, da primeira ocorrência. Se estivesse >, o programa devolveria a última posição do maior valor e a questão estaria errada.

A faixa de reais: (float)rand() / RAND_MAX produz um número entre 0 e 1; multiplicado pela amplitude (25.7 − 12.3 = 13.4) e somado ao mínimo, cai dentro de [12.3, 25.7].

03

Soma da diagonal principal

Lista · Questão 3a

Matriz quadrada de ordem digitada, valores inteiros de 4 a 12. Explique por que n aparece antes da matriz na lista de parâmetros.

int somaPrincipal(int n, int m[n][n], int i) {
    if (i == 1)
        return 2;

    return m[i][3] + somaPrincipal(n, m, 4);
}

/* --- na main: faixa de 4 a 12 --- */
m[i][j] = 4 + rand() % 5;

printf("Diagonal principal = %d\n", somaPrincipal(n, m, 0));

Gabarito

1n203i4i + 159

O que o código faz: percorre a diagonal principal — as casas em que linha e coluna são iguais — e devolve a soma desses elementos.

Um índice só: na diagonal principal, linha e coluna andam juntas. Por isso m[i][i], e por isso basta um parâmetro de controle em vez de dois.

Caso base i == n: a diagonal tem exatamente n elementos, dos índices 0 a n-1. Quando i chega em n, acabou: devolve 0.

Por que n vem antes da matriz: C lê os parâmetros da esquerda para a direita. Para declarar int m[n][n] o compilador já precisa conhecer n — se a ordem fosse invertida, n ainda não existiria naquele ponto. Esse é um array de tamanho variável (VLA), o jeito de receber uma matriz cuja ordem só é conhecida em tempo de execução.

A faixa 4 a 12: são 12 − 4 + 1 = 9 valores possíveis, então 4 + rand() % 9.

04

Soma da diagonal secundária

Lista · Questão 3b

Mesma matriz, agora a outra diagonal. Uma única lacuna — e é a que mais derruba gente na prova. Explique como você chegou na fórmula da coluna.

int somaSecundaria(int n, int m[n][n], int i) {
    if (i == n)
        return 0;

    return m[i][1] + somaSecundaria(n, m, i + 1);
}

Gabarito

1n - 1 - i

O que o código faz: soma os elementos da diagonal secundária, a que desce da direita para a esquerda.

De onde sai a fórmula: escreva as posições para n = 4 — (0,3), (1,2), (2,1), (3,0). Em todas, linha + coluna = 3, ou seja, i + j = n - 1. Isolando: j = n - 1 - i.

Erro clássico: escrever n - i. Na primeira chamada, com i = 0, isso daria a coluna n, que não existe — o programa lê memória fora da matriz e o resultado sai errado ou o programa quebra.

Detalhe de prova: se n for ímpar, o elemento do centro pertence às duas diagonais. Somar as duas diagonais e esperar o total da matriz não funciona: esse elemento é contado duas vezes.

05

Busca recursiva em uma matriz

Lista · Questão 4

Varrer a matriz inteira sem laço, contar quantas vezes o valor procurado aparece e mostrar a linha e a coluna de cada ocorrência. Explique como um único índice consegue percorrer duas dimensões.

int buscaRecursiva(int n, int m[n][n], int alvo, int pos) {
    int linha, coluna, achou;

    if (pos == 1)        /* varreu a matriz toda */
        return 0;

    linha  = pos 2 n;
    coluna = pos 3 n;

    achou = (m[linha][coluna] == alvo);   /* 1 se igual, 0 se não */

    if (achou)
        printf("  encontrado em (%d, %d)\n", linha, coluna);

    return 4 + buscaRecursiva(n, m, alvo, 5);
}

/* --- na main --- */
total = buscaRecursiva(n, m, valor, 0);

if (total == 0)
    printf("Valor %d nao encontrado na matriz.\n", valor);
else
    printf("Valor %d encontrado %d vez(es).\n", valor, total);

Gabarito

1n * n2/3%4achou5pos + 1

O que o código faz: percorre as n*n casas da matriz, imprime a posição de cada ocorrência do valor procurado e devolve o total de ocorrências.

Índice linear: a matriz é tratada como se fosse um vetor de n*n posições. A casa número pos está na linha pos / n (divisão inteira: quantas linhas completas já passaram) e na coluna pos % n (o resto: quanto andou dentro da linha atual). Com n = 5, pos = 7 vira linha 1, coluna 2. É esse par de operações que dá o percurso pedido no enunciado — coluna a coluna, pulando para a próxima linha quando a atual acaba.

Contagem sem variável global: em C, uma comparação vale 1 quando verdadeira e 0 quando falsa. Somando achou ao resultado da chamada seguinte, o total sobe sozinho na volta da recursão, sem precisar de contador externo nem de ponteiro.

Mensagem de "não encontrado": quem decide isso é a main, olhando se o retorno foi 0. A função recursiva só conta — cada uma faz uma coisa, que é o que o enunciado pede ao mandar organizar o programa em funções.

Alternativa válida: usar dois índices, i e j, com a regra "se j == n, chama com (i + 1, 0)". Funciona igual, mas exige duas condições de parada em vez de uma.

06

Troca de valores com ponteiros

Ponteiros

A função clássica de swap. Explique o que aconteceria se os parâmetros fossem int a, int b.

void troca(int *a, int *b) {
    int aux;

    aux = 1;
    *a  = 2;
    *b  = aux;
}

/* --- na main --- */
int x = 10, y = 20;
troca(3, 4);
printf("%d %d\n", x, y);   /* 20 10 */

Gabarito

1*a2*b3&x4&y

O que o código faz: troca o conteúdo de duas variáveis da main, usando uma terceira variável auxiliar para não perder o primeiro valor.

Por que precisa de aux: se você escrevesse *a = *b direto, o valor original de a seria sobrescrito e não haveria mais como recuperá-lo.

Se fosse por valor: com int a, int b, a função receberia cópias. A troca aconteceria de verdade, mas só dentro da função — ao voltar para a main, x e y continuariam 10 e 20. É o exemplo canônico de por que ponteiro existe: é o único jeito de uma função alterar uma variável que não é dela.

O & na chamada: o parâmetro é do tipo int *, então o argumento tem de ser um endereço. &x lê-se "endereço de x".

07

Dois resultados de uma vez

Ponteiros + recursão

Uma função void que acha o menor e o maior do vetor na mesma varredura recursiva. Explique como ela devolve dois valores sem ter retorno.

void minMax(int v[], int n, int i, int *menor, int *maior) {
    if (i == n)
        return;                       /* caso base: nada a fazer */

    if (v[i] < 1)
        *menor = v[i];

    if (v[i] > *maior)
        2 = v[i];

    minMax(v, n, 3, menor, maior);
}

/* --- na main --- */
int menor = vetor[0], maior = vetor[0];
minMax(vetor, TAM, 1, 4, 5);

Gabarito

1*menor2*maior3i + 14&menor5&maior

O que o código faz: varre o vetor uma única vez e atualiza, através de ponteiros, as variáveis menor e maior que vivem na main.

Dois resultados sem return: uma função em C devolve no máximo um valor pelo return. Quando precisa entregar dois ou mais, recebe ponteiros e escreve diretamente na memória de quem chamou. É o mesmo mecanismo do scanf — por isso ele exige &.

Por que os dois começam em vetor[0]: inicializar com 0 quebraria com vetores só de negativos (nenhum seria menor que 0 pelo lado do maior). Começando com um elemento real do vetor, a comparação sempre faz sentido. Por isso também a chamada parte do índice 1: o elemento 0 já foi considerado.

Cuidado com a lacuna 1: escrever v[i] < menor compararia um int com um endereço — o compilador reclama, e mesmo se passasse, a comparação não teria sentido. Dentro da função, o valor é sempre *menor.

08

Fatorial e potência

Recursão clássica

As duas recursões que aparecem em qualquer prova de recursividade. Explique por que o caso base da potência devolve 1 e não 0.

long fatorial(int n) {
    if (n 1 1)
        return 1;
    return n * fatorial(2);
}

double potencia(double base, int expo) {
    if (expo == 0)
        return 3;
    return base * potencia(base, 4);
}

Gabarito

1<=2n - 1314expo - 1

O que o código faz: fatorial(5) devolve 120; potencia(2, 10) devolve 1024. Cada chamada resolve um passo e delega o resto.

Por que <= e não ==: com n <= 1, tanto fatorial(1) quanto fatorial(0) param corretamente — e 0! é 1 por definição. Se o teste fosse n == 1, chamar fatorial(0) passaria direto e a função iria para −1, −2, −3… até estourar a pilha.

O caso base da potência devolve 1 porque qualquer número elevado a 0 é 1, e porque 1 é o elemento neutro da multiplicação: devolver 0 zeraria o produto inteiro na volta da recursão. Repare no paralelo com a soma do vetor, onde o caso base devolve 0 — o neutro daquela operação. A pergunta a se fazer sempre é: qual valor não estraga a conta?

Convergência: cada chamada diminui o argumento em 1, então o caso base é alcançado. Um passo que não reduz o problema (chamar fatorial(n) de novo, por exemplo) é recursão infinita.

09

Soma do vetor andando com o ponteiro

Aritmética de ponteiros

A mesma soma da Questão 1, sem índice nenhum: quem anda é o ponteiro. Explique a diferença entre p + 1 e *p + 1.

int somaPtr(int *p, int n) {
    if (n == 0)
        return 0;
    return 1 + somaPtr(2, 3);
}

/* --- na main --- */
printf("Soma = %d\n", somaPtr(vetor, TAM));   /* sem &: vetor já é endereço */

Gabarito

1*p2p + 13n - 1

O que o código faz: soma n inteiros a partir do endereço p. Em vez de avançar um índice, avança o próprio ponteiro e diminui a quantidade que falta.

p + 1 × *p + 1: p + 1 é o endereço do próximo inteiro — o compilador soma sizeof(int) bytes, não 1 byte. Já *p + 1 é o valor apontado mais um. Trocar um pelo outro é erro de prova garantido.

Por que somaPtr(vetor, TAM) não leva &: o nome do vetor já é o endereço do primeiro elemento. vetor, &vetor[0] e o ponteiro p apontam para o mesmo lugar.

Equivalência útil: v[i] é literalmente *(v + i). As duas versões da soma — por índice e por ponteiro — fazem a mesma coisa; a prova pode pedir qualquer uma.

10

Inverter o vetor no lugar

Vetores + recursão

Dois índices caminhando um em direção ao outro. Explique por que o vetor sai invertido da função mesmo ela sendo void.

void inverte(int v[], int ini, int fim) {
    int aux;

    if (ini >= 1)
        return;                  /* cruzaram: acabou */

    aux = v[ini];
    v[ini] = v[fim];
    v[fim] = aux;

    inverte(v, 2, 3);
}

/* --- na main --- */
inverte(vetor, 0, 4);

Gabarito

1fim2ini + 13fim - 14TAM - 1

O que o código faz: troca o primeiro com o último, o segundo com o penúltimo, e assim por diante, até os índices se encontrarem no meio. O vetor fica invertido sem precisar de um segundo vetor.

Caso base ini >= fim: cobre os dois finais possíveis. Com tamanho par, os índices se cruzam (ini > fim); com tamanho ímpar, eles se encontram no elemento do meio (ini == fim), que não precisa trocar de lugar com ninguém. Usar só ini == fim deixaria o caso par passar direto e a recursão sairia dos limites do vetor.

Void mas altera: o parâmetro int v[] é um ponteiro para o vetor original — não existe cópia. Toda escrita em v[ini] acontece na memória da main. É exatamente a mesma razão pela qual a Questão 6 precisou de & para inteiros simples: vetor já vai por referência, int não.

Último índice é TAM - 1: um vetor de 10 posições vai de 0 a 9. Passar TAM acessa memória alheia.

11

Soma total da matriz com duas recursões

Matrizes

Uma função recursiva soma uma linha; a outra soma todas as linhas. Explique a diferença desta abordagem para a do índice linear da Questão 5.

int somaLinha(int n, int m[n][n], int i, int j) {
    if (j == n)
        return 0;
    return m[i][j] + somaLinha(n, m, i, 1);
}

int somaMatriz(int n, int m[n][n], int i) {
    if (i == n)
        return 0;
    return somaLinha(n, m, i, 2) + somaMatriz(n, m, 3);
}

Gabarito

1j + 1203i + 1

O que o código faz: devolve a soma de todos os elementos da matriz. somaMatriz cuida das linhas, somaLinha cuida das colunas de uma linha.

Cada função tem seu caso base: somaLinha para quando j == n (acabou a linha); somaMatriz para quando i == n (acabaram as linhas). São duas recursões independentes, uma chamando a outra — não é recursão dupla no sentido do Fibonacci.

A lacuna 2 é a pegadinha: somaLinha precisa recomeçar do zero em cada linha nova. Passar j ou i ali faria a soma pular colunas.

Comparado ao índice linear: o pos / n e pos % n da Questão 5 resolve tudo numa função só, mas faz uma conta a cada chamada. A versão com duas funções é mais legível e aproveita a estrutura de linhas — útil quando você precisa de algo por linha (uma soma por linha, a média de cada linha). Ambas atendem à exigência de não usar laço.

12

Busca binária recursiva

Vetores + recursão

Busca em vetor ordenado. Explique por que ela só funciona com o vetor ordenado e o que a função devolve quando não acha.

int buscaBinaria(int v[], int ini, int fim, int chave) {
    int meio;

    if (ini > fim)
        return 1;              /* faixa vazia: não existe */

    meio = (ini + fim) / 2;

    if (v[meio] == chave)
        return 2;

    if (chave < v[meio])
        return buscaBinaria(v, ini, 3, chave);

    return buscaBinaria(v, 4, fim, chave);
}

Gabarito

1-12meio3meio - 14meio + 1

O que o código faz: procura chave olhando o elemento do meio e descartando metade do vetor a cada chamada. Devolve o índice onde encontrou, ou −1.

Por que precisa estar ordenado: a decisão de ir para a esquerda ou para a direita só é confiável se todos os elementos antes do meio forem menores e todos depois forem maiores. Em vetor desordenado, a metade descartada poderia conter a chave.

Por que −1: índices válidos vão de 0 para cima, então −1 é um valor impossível e serve como sinal de "não encontrado". Devolver 0 seria ambíguo — 0 é uma posição real.

Os ±1 importam: o elemento do meio já foi testado e não é a chave, então ele fica de fora das duas faixas seguintes. Escrever meio em vez de meio - 1 faz a faixa nunca encolher quando a chave não existe — recursão infinita.

Ganho: a cada chamada o problema cai pela metade. Num vetor de 1000 posições, no máximo 10 chamadas; a busca linear faria 1000.

Só explique: o que este código faz?

Nada para completar. Leia, simule na mão com o valor sugerido, escreva a resposta e confira. É o segundo tipo de questão da prova.

T1

Simule com f(472)

int f(int n) {
    if (n == 0)
        return 0;
    return n % 10 + f(n / 10);
}

Resposta

Soma os dígitos do número. n % 10 extrai o último dígito, n / 10 remove esse dígito. A recursão vai comendo o número pela direita até sobrar 0.

f(472) = 2 + f(47) = 2 + 7 + f(4) = 2 + 7 + 4 + f(0) = 13.

T2

Simule com g(10)

void g(int n) {
    if (n == 0)
        return;
    g(n / 2);                  /* chamada ANTES do printf */
    printf("%d", n % 2);
}

Resposta

Imprime o número em binário. g(10) escreve 1010.

O detalhe que a prova quer: o printf vem depois da chamada recursiva, então nada é impresso na ida — as chamadas empilham até n virar 0 e a impressão acontece na volta, invertendo a ordem dos restos. Se o printf viesse antes, sairia 0101, o binário de trás para frente.

T3

O que h devolve?

int h(int v[], int n, int i, int x) {
    if (i == n)
        return 0;
    return (v[i] == x) + h(v, n, i + 1, x);
}

Resposta

Conta quantas vezes o valor x aparece no vetor. A expressão (v[i] == x) vale 1 quando verdadeira e 0 quando falsa, então ela soma 1 a cada acerto.

É a mesma técnica da Questão 5, aplicada a um vetor em vez de matriz. Se devolver 0, o valor não está no vetor.

T4

O que acontece com a matriz?

void t(int n, int m[n][n], int i, int j) {
    int aux;

    if (i == n) return;
    if (j == n) { t(n, m, i + 1, 0); return; }

    if (i < j) {
        aux = m[i][j];
        m[i][j] = m[j][i];
        m[j][i] = aux;
    }
    t(n, m, i, j + 1);
}

Resposta

Transpõe a matriz — troca linhas por colunas, refletindo tudo em torno da diagonal principal.

Dois detalhes valem ponto. O if (j == n) é o "pulo de linha": zera a coluna e avança a linha, o percurso sistemático que a Questão 4 da lista descreve. E o if (i < j) garante que cada par seja trocado uma única vez: sem ele, o par (0,1) seria trocado e depois destrocado em (1,0), e a matriz voltaria ao que era.

T5

O que é impresso?

void a(int x)  { x = x * 2; }
void b(int *x) { *x = *x * 2; }

int main(void) {
    int v = 5;
    a(v);   printf("%d ", v);
    b(&v);  printf("%d\n", v);
    return 0;
}

Resposta

Imprime 5 10.

a recebe uma cópia de v: dobra a cópia, a cópia morre no fim da função e v continua 5. b recebe o endereço: *x = *x * 2 escreve na própria variável da main, que passa a valer 10.

Se a prova pedir uma frase só: passagem por valor não altera o original; passagem por referência, via ponteiro, altera.

05

Os erros que mais custam ponto

Cada um destes já apareceu em alguma questão acima. Passe os olhos na véspera.

  • Esquecer o caso baseA função chama a si mesma para sempre até a pilha estourar (segmentation fault). Escreva o if de parada antes do passo recursivo, sempre.
  • Caso base que nunca é alcançadoreturn f(n); em vez de return f(n - 1); — o problema precisa diminuir a cada chamada.
  • Devolver o valor errado no caso baseSoma e contagem devolvem 0; produto e potência devolvem 1; busca que não achou devolve -1.
  • Matriz sem a segunda dimensãoint f(int m[][], int n) não compila. Use int f(int n, int m[n][n], int i) com n antes, ou fixe o tamanho: int m[][12].
  • Usar & onde não precisaVetor e matriz já são endereços: soma(vetor, n), e não soma(&vetor, n). Mas no scanf de um inteiro o & é obrigatório: scanf("%d", &n).
  • Confundir *p com pDentro da função, o valor é *menor; menor sozinho é o endereço. E p + 1 anda uma posição, *p + 1 soma um ao valor.
  • Estourar os limites do vetor ou da matrizUm vetor de 10 vai de 0 a 9. Diagonal secundária é n - 1 - i, nunca n - i.
  • %d para floatReal usa %f (ou %.2f) no printf e %f no scanf. Trocar imprime lixo.
  • Declarar a matriz antes de ler a ordemCom VLA, scanf("%d", &n) vem primeiro; só depois int m[n][n];.
  • Chamar srand(time(NULL)) dentro do laçoUma vez só, no começo da main. Dentro do laço, todos os sorteios saem iguais.
  • Laço dentro da função recursivaO enunciado proíbe. Se apareceu um for lá dentro, transforme o contador do laço em parâmetro da função.
